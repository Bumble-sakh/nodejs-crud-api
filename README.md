# 🚀 Welcome to node-crud-api

Simple CRUD API using in-memory database

_You can set the port in the `.env` file or in the launch script using `cross-env`_

_`cross-env` has higher priority than `.env`_

### 💡 Start in development mode with automatically reload:

```
npm run dev
```

### 💡 Start in production mode:

```
npm run start:prod
```

### 💡Start in production mode with a load balancer:

```
npm run start:multi
```
